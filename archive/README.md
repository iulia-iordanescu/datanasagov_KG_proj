# Archive

Old material, kept for reference. Nothing here is run, and no code imports it: the [steps](../docs/terminology.md#8-the-pipeline) never read it, and the tests check only this README. The code in `to_be_reshaped/` says how those scripts behaved; their own comments and notes may be out of date, so I don't rely on them.

| Folder | What it holds | Where it was | Moved here |
|---|---|---|---|
| `to_be_reshaped/` | The scripts from before the pipeline, kept as reference while their work moves into the steps; among them `nasa_harvest.py` and `nasa_census.py`, which built Phase 1. Never run them. | `to_be_reshaped/`, at the top of the repository, since 2026-09-27 | 2026-10-24 |
| `annotations/` | The [classed triples](../docs/terminology.md#2-triples) a model drafted before the pipeline existed, in five files (`draft_triples_batch1–5`, each a CSV and its [settings](../docs/terminology.md#8-the-pipeline)), for 3 of the 6 [records](../docs/terminology.md#1-records-and-their-text) in `annotations/ground_truth/batch_000.csv`; and `schema_notes_derived_from_manual_annotation.txt`, the notes the [ground truth schema](../docs/terminology.md#3-schemas) started from. | `annotations/archive/`, since 2026-09-28 (the schema notes since 2026-10-14) | 2026-10-24 |

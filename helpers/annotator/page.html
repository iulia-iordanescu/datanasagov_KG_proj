    Annotating ground truth

    1. Choose a batch at the top, under “Batch”. A batch is one file of records to annotate.
    2. Read the Guidelines (the button next to the batch) before the first record: they say what to write.
    3. For each record: read the record's text, then correct, delete or add its ground truth triples, and tick “All facts extracted” when every fact the text states has a ground truth triple.
    4. When the batch is done, commit its file (annotations/ground_truth/batch_NNN.csv) to Git.

    Every change is saved to the file as you type. Help, at the top right, explains the view you are on.

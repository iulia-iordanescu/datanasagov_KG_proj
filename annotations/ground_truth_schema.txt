ENTITY CLASSES
--------------
Each entry below is marked for rule 19 of Writing a classed triple (annotations/guidelines.md), on a line
under it: "rule 19: standalone" (a standalone entity class: its instances exist on their own and have facts
of their own, so a qualifier taken out of its instance becomes that instance's ground truth triple) or
"rule 19: describing" (a describing entity class: its instances only describe something else, so the
qualifier becomes the ground truth triple of the subject of the triple whose object the instance was, in the
sentence the qualifier is in).
# CatalogEntry, the subject class of the describes triple, is not listed: code writes it, never a person.

Dataset           a set of observations, measurements, or samples
                  rule 19: standalone
WebTool           a tool used over the web
                  rule 19: standalone
Software          a computer program, e.g. example C-language program
                  rule 19: standalone
                  source: ground truth tuning #16
FileFormat        a way data are encoded in files, e.g. GeoTIFF; zip
                  rule 19: standalone
                  source: ground truth tuning #22, #24, #25
Document          a written publication, or a set of them, named in words or by a reference key, e.g. NASA developed standards; LAWRENCEETAL2013
                  rule 19: standalone
                  source: ground truth tuning #0, #5
Purpose           an aim something is meant to achieve
                  rule 19: describing
Mission           a named effort to collect data, from space, from the air, on water or on the ground, e.g. Rosetta; BARREL
                  rule 19: standalone
MissionPhase      a named phase of a Mission
                  rule 19: standalone
Campaign          a named period of field measurements from balloons, aircraft, ships or the ground, carried out as part of a Mission, e.g. August 2015 BARREL campaign
                  rule 19: standalone
                  source: ground truth tuning #19
Discipline        a field of science
                  rule 19: describing
Organization      a named institution or one of its named parts, not a Mission, e.g. NASA; OBPG
                  rule 19: standalone
Instrument        a device that takes measurements
                  rule 19: standalone
Platform          a craft or station that carries Instruments, in space, in the air, on water or on the ground: a spacecraft, an aircraft, a balloon, a ship or a ground station, e.g. Aqua; Voyager 1
                  rule 19: standalone
Time              a point or period on the calendar, which happens once, e.g. March 11, 2016 19:08:03; May 4, 2002; first week of February 2003; 2015-10-22 to 2015-12-31
                  rule 19: describing
PhysicalQuantity  a bare property that can be measured, whatever method measures it, e.g. temperature; gravity; sea surface temperature; snow cover; not a form the data take, such as images, image cubes, spectra or maps (a SpatialRepresentation)
                  rule 19: describing
CelestialBody     a natural object in space, or a kind of such objects, e.g. Vesta; active galactic nuclei
                  rule 19: standalone
Version           a label that marks one release of something
                  rule 19: describing
SpatialExtent     an area the data cover, of the CelestialBody they are about: all of it (global) or part of it (e.g. Arctic; south pole of Mars; a country, when the data cover it)
                  rule 19: describing
ProcessingLevel   a stage of processing: how far data have been processed from what the Instrument recorded, e.g. Level 2
                  rule 19: describing
Value             an amount, or a range of amounts, as a number with its unit or in words, e.g. 36 spectral bands; 5 minutes
                  rule 19: describing
Unit              a unit that values are given in, e.g. instrument data numbers; W/m^2/sr/nm
                  rule 19: describing
                  source: ground truth tuning #13, #16
Algorithm         a method applied to data to compute a result, e.g. series of screens; modified nonlinear SST algorithm
                  rule 19: standalone
                  source: ground truth tuning #2
Identifier        a code that names one thing, or one product line, permanently, e.g. a DOI; MOD11A1
                  rule 19: describing
                  source: ground truth tuning #2
SpatialRepresentation  a form data are laid out in: over the ground, typically along a satellite's path, as observed (swath), or on a fixed map grid (gridded); or as images, image cubes, spectra or maps, e.g. swath; map; raw near-IR spectral image cubes
                       rule 19: describing
                       source: ground truth tuning #2
Country           a nation, as where a Person or Organization is based, e.g. U.S.; Argentina
                  rule 19: standalone
                  source: ground truth tuning #3
TimeOfDay         a point or period in the day, which comes back every day, e.g. 2:39 PM; morning; nighttime
                  rule 19: describing
                  source: ground truth tuning #4
Orbit             a path a spacecraft travels around a CelestialBody
                  rule 19: describing
                  source: ground truth tuning #4
SatelliteFormation  a group of spacecraft flying together in formation in orbit, e.g. A-train
                    rule 19: standalone
                    source: ground truth tuning #4
Channel           a range of wavelengths an Instrument measures separately, e.g. 11 micron channel
                  rule 19: standalone
                  source: ground truth tuning #4
Phenomenon        something that happens in nature and can be observed, e.g. sun glint
                  rule 19: standalone
                  source: ground truth tuning #4
Grid              a fixed set of cells or points that data values are given on, e.g. ISEAG; pressure grid with 24 levels per decade
                  rule 19: standalone
                  source: ground truth tuning #4
MapProjection     a way of drawing the curved Earth on a flat map, e.g. equidistant cylindrical
                  rule 19: describing
                  source: ground truth tuning #4
CoordinateSystem  a set of rules for giving positions as coordinates, other than a way of drawing the Earth on a map (a MapProjection), e.g. Heliographic Inertial, HGI, Coordinates
                  rule 19: describing
                  source: ground truth tuning #15
WebPage           a web address, written as the address itself, other than a DOI written as an address (an Identifier), e.g. https://oceancolor.gsfc.nasa.gov/docs/format/
                  rule 19: describing
                  source: ground truth tuning #4
EmailAddress      an email address, written as the address itself, e.g. Robyn.Millan@dartmouth.edu
                  rule 19: describing
                  source: ground truth tuning #19
Task              a piece of work a Person or Organization does or is in charge of, e.g. quality flagging
                  rule 19: describing
                  source: ground truth tuning #4
Role              a position only one Person or Organization holds (rule 4), e.g. official archive for SST; Argentina's space agency
                  rule 19: describing
                  source: ground truth tuning #4
Variable          a property narrowed by a method, a band, a threshold, another object or another constraint, e.g. SST4; NDSI; band 31 emissivity; dust fluences at each of twelve mass thresholds
                  rule 19: standalone
                  source: ground truth tuning #4
Person            one named human being, e.g. Peter Minnett
                  rule 19: standalone
                  source: ground truth tuning #4
SpatialResolution  an amount of ground each value of the data covers, e.g. 500 m; 4.63 km
                   rule 19: describing
                   source: ground truth tuning #2, #4
TemporalResolution  an amount of time between one value of the data and the next, e.g. daily; weekly (8 day)
                    rule 19: describing
                    source: ground truth tuning #2, #3, #4
Issue             a problem that affects how data are made or used, e.g. loss of data retrieval
                  rule 19: describing
                  source: ground truth tuning #7
AccessRights      who may use something, and on what terms, e.g. freely available to the public
                  rule 19: describing
                  source: ground truth tuning #19
Technique         a way of making measurements, e.g. radio science
                  rule 19: describing
                  source: ground truth tuning #1
Latency           a measure of how soon data are released after observation, e.g. Near Real Time (NRT)
                  rule 19: describing
                  source: ground truth tuning #6

PREDICATES
----------
Each entry below reads subject -> object, and lists its patterns (subject class -> object class).
Every pattern the ground truth itself uses counts too (code reads them from the
ground truth files), so a new pattern is never added here. Use a predicate
wherever its meaning fits.
A line "only: Subject -> Object; ..." pins a predicate: it joins only those
entity classes ("any": any entity class), and the checks flag any other pattern.
A predicate whose definition names its object's entity class is pinned to it.
A line "rule 19: qualifier, ..." marks a qualifier predicate: one of the qualifiers that rule 19 of
Writing a classed triple takes out of an instance, named in the rule's words.

EXAMPLE SCHEMA

ENTITY CLASSES
--------------
Dataset              a set of observations, measurements, or derived values
Instrument           a device that measures, or a part of one
Spacecraft           a vehicle that flies in space
Organization         a named institution or one of its named parts
PhysicalQuantity     a property that can be measured
Content              what a dataset holds, in its own words
Algorithm            a method applied to data to compute a result
Channel              a wavelength band an instrument measures in
Purpose              what something is for
CelestialBody        a natural body in space
SpatialExtent        the area the data cover
TemporalResolution   the time between one value of the data and the next
SpatialResolution    the amount of ground or sky each value of the data covers
ProcessingLevel      how far the data are processed
Version              a release of a dataset
Time                 a point or period of time
MissionPhase         a named period of a mission
AngleRange           a range of angles

PREDICATES
----------
Each entry reads subject -> object, with its patterns (subject class -> object class).

HAS_MEASUREMENTS_OF      holds measurements of this
                         Dataset -> PhysicalQuantity
HAS_CONTENT              holds this
                         Dataset -> Content
HAS_TEMPORAL_RESOLUTION  gives values this often
                         Dataset -> TemporalResolution
HAS_SPATIAL_COVERAGE     covers this area
                         Dataset -> SpatialExtent
HAS_SPATIAL_RESOLUTION   each of its values covers this much ground
                         Dataset -> SpatialResolution
HAS_PROCESSING_LEVEL     is processed to this level
                         Dataset -> ProcessingLevel
HAS_VERSION              is this release
                         Dataset -> Version
ACQUIRED_BY_INSTRUMENT   was collected by this instrument
                         Dataset -> Instrument
FROM_SPACECRAFT          came from this spacecraft
                         Dataset -> Spacecraft
ABOARD                   is carried by this spacecraft
                         Instrument -> Spacecraft
HAS_PART                 has this as one of its parts
                         Instrument -> Instrument
LAUNCHED_BY              was launched by this organization
                         Spacecraft -> Organization
HAS_TARGET               is about this body
                         Spacecraft -> CelestialBody; Content -> CelestialBody
HAS_PURPOSE              is meant to do this
                         Spacecraft -> Purpose; Content -> Purpose
COMPUTED_FROM            is computed from this input
                         Dataset -> PhysicalQuantity; PhysicalQuantity -> Channel
PRODUCED_USING_ALGORITHM  is computed with this method
                         Dataset -> Algorithm
PRODUCED_BY              was made by this organization
                         Content -> Organization
HAS_TIME_SPAN            covers this period
                         Dataset -> Time
HAS_MISSION_PHASE        was observed during this phase
                         Dataset -> MissionPhase
HAS_LOWER_NOISE_THAN     has lower noise than this
                         Instrument -> Instrument
HAS_PHASE_ANGLE_RANGE    covers phase angles in this range
                         Dataset -> AngleRange
